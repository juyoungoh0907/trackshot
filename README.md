# TrackShot

240fps 슬로모션 투구 영상으로 구속을 재고, 궤적 선과 회전 애니메이션이 들어간 영상을 만드는 웹앱입니다. 빌드가 필요 없는 정적 사이트입니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (화면, 측정, 영상 저장) |
| `vendor/mp4-muxer.js` | mp4 파일 생성 라이브러리 (MIT, `vendor/mp4-muxer-LICENSE`) |
| `manifest.webmanifest`, `icon.svg`, `icon-*.png`, `apple-touch-icon.png` | 홈 화면 추가용 아이콘 |

## Vercel 배포

1. GitHub에 새 저장소를 만들고, 이 폴더 안의 파일을 저장소 맨 위(루트)에 올립니다.
2. vercel.com에서 **Add New → Project**를 누르고 방금 만든 저장소를 선택합니다.
3. 설정은 다음처럼 둡니다.
   - Framework Preset: **Other**
   - Build Command: 비워 둠
   - Output Directory: 비워 둠 (루트)
4. **Deploy**를 누르면 `https://프로젝트이름.vercel.app` 주소가 생깁니다.

이후 GitHub에 파일을 수정해 올리면 자동으로 다시 배포됩니다.

## 휴대폰에서 앱처럼 쓰기

- 아이폰(사파리): 공유 버튼 → 홈 화면에 추가
- 안드로이드(크롬): 메뉴 → 홈 화면에 추가

## 사용법

1. 240fps 슬로모션 영상을 불러옵니다.
2. `+1`을 여러 번 눌러야 화면이 한 번 움직이면 측정 설정에서 '8배 느리게 저장됨'을 고릅니다.
3. 공이 손을 떠나는 프레임에서 공을 누르고, 프레임을 넘기며 3~6번 더 누른 뒤, 공이 타깃에 닿는 프레임에서 마지막으로 누릅니다.
   - 누른 채로 움직이면 확대경을 보며 위치를 맞출 수 있습니다.
   - 아래 점 목록에서 점을 누르면 그 프레임으로 이동하고, ×를 누르면 지워집니다.
   - +1, −1 버튼은 길게 누르면 연속으로 넘어갑니다.
4. 구종과 저장 영상 속도를 고르고 **영상 저장**을 누릅니다.
